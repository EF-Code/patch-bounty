# Continue PatchBounty

This repository contains a complete runnable operator application for the fixed synthetic authorization challenge. Read [README.md](README.md), [application setup and workflows](docs/APPLICATION.md), and [the implementation scope](docs/ROADMAP.md). The responsive browser app supports challenge funding, manual/sample/AI proposals, claim submission, sandbox verification, explicit settlement, expiry refunds, failed-payout retries, evidence downloads and run exports. Its local mode uses a real NEAR node with simulated funds; dedicated testnet mode is also implemented and verified. Start through `scripts/setup.sh` and `scripts/start.sh` (use the explicit `--low-fd` compatibility option on this environment).

The latest application testnet run and its public transaction journal are in [demo/app-testnet-20261107](demo/app-testnet-20261107/README.md). It includes an RPC interruption found during testing and a successful payout after the application was hardened to journal signing hashes and recover receipts without rebroadcast. The current provider is the officially documented `https://test.rpc.fastnear.com`; the older public NEAR RPC returned a deprecation/rate-limit error. A [full application recording](demo/VIDEO.md) now captures actual local-chain operations.

The first live `generate.py --near-ai` run produced a qualifying synthetic candidate, which was independently checked by `verifier.py`; see [the saved run](demo/near-ai-20261107/README.md). The integration does not verify gateway/model attestations or response signatures. [AI verification](docs/AI-VERIFICATION.md) records current checks, failure handling, and requirements for a future verified mode. The delivered AI feature is explicitly synthetic-only generation; confidential inference is outside this non-production application scope and must not be claimed. Only the deterministic verifier may determine eligibility; model output cannot authorize payment.
