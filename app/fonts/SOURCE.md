# Font assets

Self-hosted Latin WOFF2 assets retrieved from Google Fonts on 2026-11-13:

- Instrument Sans, variable weights 400–700 (Google Fonts release v4).
- IBM Plex Mono, regular 400 (Google Fonts release v23).

The accompanying OFL license files retain the font copyright notices and terms. Source families: https://github.com/google/fonts/tree/main/ofl/instrumentsans and https://github.com/google/fonts/tree/main/ofl/ibmplexmono. The browser loads these files from the application origin; it makes no request to Google Fonts at runtime.
